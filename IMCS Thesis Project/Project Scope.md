# MATH1010U Educational Game

## Description
Develp and test an educational math game for the material covered in MATH1010U though the creation of three mini games for three overarching topics. This game will target students who might have struggled in the course in the previous semster, and who could benefit from a contextual and interactive medium to engange with the material. 

## Deadline
April 12th 2027 

## Goals 
1. Create an educational math game that allows students to engange with the material of 1010U through interactive and contextual gameplay.
2. Evaluate the effectiveness of the math game by self reported student engagement and a test of student ability. 

## Deliverables
The first deliverable will be the educational math game program packaged as an executable file (.exe). The second deliverable will be an analysis of the data collected from testing the game with students of MATH 1010U.

## Tasks
1. Create a single player educational game focused on overarching 1010U Topics:
	- Create Github repository to track and document changes
	- Create algorithm to generate equations for use in game 
	- Create a mini game for each of the three overarching topics: Limits, Derivatives, and Integrals
	- Create system to adjust the level difficulty dynamically based on students performance
	- Develop a system to create a profile in the game to track and store game performance via a randomly generated user id
	- Allow for students to see their highscores and recent scores

2. Test Effectiveness of Educational Game:
	- Create system to aggregate and store the data collected by the game 
	- Deploy the game executable to lab computers
	- Evaluate students ability to solve integral problems using techniques, and their attitude towards practicing and learning integral techniques
	- After students play the game, re-evaluate students ability to solve integral problems using the techniques, and ask if the game affected their attitude towards practicing and learning integral techniques
	- Combine the data collected in person from students with the data collected in game on those students




## Out of scope Tasks
- Create an opt-in leaderboard for student scores  
- Utilize assets made by friends (sprites and music) to add charm and engagement to game

## Constraints 
- Must complete research ethics board application by end of October
- One Mini Game Finished by January
- Need playable version of the game by March 2027 for student testing
- Final version of game and analysis of data completed by April 1st
- Report completed by April 12th
